# Live Deck Studio

Studio 是 Live Deck v1 文稿的结构化编辑器。它仍然以 JSON 为唯一可分发格式，但把最常修改的对象、引用和校验结果做成表单视图。

入口：

- 播放器顶部 **Studio**；
- 直接打开 `custom/live-deck/studio.html`；
- 示例窗口保留查询参数，例如 `studio.html?deck=multi-panel`。

## 工作方式

- **保存草稿**只写当前浏览器的 `<播放器存储键>:studio-draft`，不会改变正在使用的播放器文稿。
- **应用并打开**先执行结构、引用、产品能力和运行事件回放检查；没有阻塞错误时，才写入播放器浏览器副本和固定 tab 元数据。
- **导入**先把文件解析为 Studio 草稿；**导出**生成标准 `*.livedeck.json`；**重载发布稿**会在确认后丢弃当前草稿并重新读取入口发布文件。
- 撤销和重做覆盖表单、页面排序和原始 JSON 应用；草稿自动保存默认延迟约 550 ms。
- Studio 不会执行文稿中的 Shell 命令，也不会创建真实终端、Jupyter kernel 或 Grafana 请求。

## 页面

左侧是大纲，中间是静态结构预览，右侧是属性检查器。

页面检查器支持：

- 文稿标题、ID、`revision` 和 `monitoringRevision`；
- 页面标题、稳定 ID、`kicker` 和 `speakerNotes`；
- `slide` 的 Markdown；
- `terminal` 的目标终端；
- `workspace` 的固定面板、布局和监控组；
- 页面排序、新建和删除。

Studio 会给新页面生成 `page-N` 形式稳定 ID。旧文稿缺少页面 ID 时仍可播放，但会收到非阻塞提示。

## 面板与命令

面板检查器支持：

- 新建终端和网页面板；
- 修改显示名称，并把面板 ID 重命名安全传播到页面、`sequence`、监控组、图表 binding 和 `preview`；
- 终端 `cwd`、独立演示进度和固定 tabs；
- 网页面板 URL、运行绑定和 Live Deck 时序图；
- 候选动作的标题、ID、命令/URL、说明、预期观察和目标 tab；
- 命令与 tab 排序、添加和删除。

仍被页面、计划、binding、监控组或 preview 引用的面板不能直接删除；仍被命令或图表引用的 tab 也不能删除。错误会保留原对象，不会用清空引用的方式强行删除。

## 演示计划

计划检查器支持面板步骤和监控组步骤，允许选择面板、命令、tab、排序和删除。Studio 不自动执行步骤，只编辑播放器使用的手动 `sequence`。

## 原始 JSON

任何表单暂未覆盖的字段都可以在 JSON 模式编辑。应用 JSON 后会重新生成结构视图并执行校验。未定义字段会显示为警告；它们仍保留在文稿中，以兼容后续版本和上游扩展。

## 检查

“检查”页同时运行：

1. 结构、类型、ID 唯一性和跨对象引用校验；
2. 产品能力校验，包括指标目录和图表阶段能力；
3. 隔离的事件回放，检查图表运行生命周期；
4. Studio 静态提示，例如相对 `cwd`、多行候选命令、HTTP 链接和缺失命令 ID。

这些检查不验证目标机器上的目录、脚本、权限、终端登录或 Grafana 实际数据。真实放映前仍必须在目标环境中排练。
